# Md. Kabir Hossain — Portfolio Website

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract `kabir_hossain_portfolio.zip`.
2. Open `index.html` in any modern browser.

No build tools or dependencies are required.

## Customize before publishing
Open `index.html` and replace:
- `your.email@example.com` with your professional email.
- LinkedIn and GitHub URLs with your actual profile URLs.
- Add a real project portfolio, measurable outcomes, certifications and professional photo if desired.

Review all skill descriptions and only retain tools/technologies that reflect your actual experience.

## Publish
Upload `index.html`, `style.css`, and `script.js` to any static hosting provider such as GitHub Pages, Netlify, or your own web hosting.

## Files
- `index.html` — page content and structure
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and current year
