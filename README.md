## Folder Structure for GitHub Pages

Before pushing to GitHub, place your portrait image (`1000002099.jpg`) in the **same root folder** as `index.html`:

```text
your-repo/
├── index.html
├── 1000002099.jpg
└── README.md
```

## How to Deploy on GitHub Pages (Free Hosting)

1. Create a new public repository on GitHub (e.g., `kabir-portfolio` or `yourusername.github.io`).
2. Upload `index.html`, `1000002099.jpg`, and `README.md` to the root of the repository.
3. Go to **Repository Settings → Pages**.
4. Under **Build and deployment → Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your live portfolio will be published at `https://<your-username>.github.io/<repo-name>/`.
